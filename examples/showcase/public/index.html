rucloud showcase

每張卡片示範一種 Cloudflare Workers 的綁定，按下去就會呼叫這個 Worker 的 /api/*，結果是真的在這台主機上執行出來的。靜態檔案（這一頁）由 Rust 直接回應。

D1 資料庫 env.DB

SQLite 資料庫。每按一次新增一筆紀錄，回傳總筆數。


    


    

      
KV env.KV

      
鍵值儲存。造訪計數存在 visits 這個鍵。

      

      

    


    

      
Durable Object env.COUNTER

      
強一致的計數器：同一個名稱永遠是同一個實例，同時有很多人按也不會算錯。

      

      

    


    

      
Queues env.JOBS

      
送一個工作進佇列，背景的消費者（queue()）處理完會把完成數加一。稍後再按一次就會看到 done 增加。

      

      

    


    

      
Cron scheduled()

      
排程每分鐘執行一次，把執行時間寫進 KV。

      

      

    


    

      
Vectorize env.VECTORS

      
向量搜尋：存入 cat、dog、car 三個向量，查詢最像 cat 的兩個。

      

      

    


    

      
Rate Limiting env.LIMITER

      
每個 IP 每 60 秒最多 3 次。按下去會連續送 5 個請求，超過的會被擋下（429）。

      

      

    


    

      
Service binding env.HELLO

      
不經過網路，直接呼叫同一台 rucloud 上的另一個應用（hello）。

      

      

    


    

      
R2 物件儲存 env.FILES

      
上傳一段文字成為檔案。示範用：每個檔案最大 32 KB，最多保留 30 個，超過會刪掉最舊的。

      
      
      

      
    
      
    
    
    

    
    
      
    HTMLRewriter
    
      
    用串流的方式改寫 HTML：拿這一頁，把標題換成造訪次數，再插入一個連結。
    
      
    
    
    

    
    
      
    環境變數 vars
    
      
    wrangler 設定裡的 vars，Worker 從 env 讀到。
