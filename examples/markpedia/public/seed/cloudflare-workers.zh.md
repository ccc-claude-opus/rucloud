## 概述

**Cloudflare Workers** 是執行在 Cloudflare 邊緣節點的無伺服器平台，可直接以 JavaScript 處理使用者的 HTTP 請求，省去管理來源伺服器的工作。程式碼被推送到全球數百座城市的據點就近執行，路由判斷、內容改寫與快取可在數十毫秒內完成。

## 執行模型與演進

Workers 於 2018 年推出測試版，2019 年轉為正式服務。其執行環境是 V8 的 isolate，而非虛擬機器或容器：每個 isolate 擁有獨立記憶體與堆疊，啟動成本極低，因而不必等待傳統雲端常見的「冷啟動」。2020 年之後平台陸續加入 KV、Durable Objects、R2 物件儲存與 D1 資料庫等產品線，使它從單純的邊緣腳本擴展成完整的應用平台。

## 計費與技術限制

Workers 提供免費與付費兩種方案，請求額度與運算時間上限是選型時最主要的考量。計費以請求次數為單位，另依使用的 CPU 時間與外部服務用量加計，因此預算較容易估算。

| 項目 | 規格 |
| --- | --- |
| 執行環境 | V8 isolate（隔離執行，非容器） |
| 冷啟動 | 無等待，isolate 預先就緒 |
| 免費額度 | 每日 100,000 次請求 |
| 付費額度 | Workers Paid 每月含 1,000 萬次請求 |
| 免費方案運算上限 | 每次請求 10 ms CPU 時間 |
| 網域 | 需綁定自訂網域或使用 workers.dev 子網域 |

## 適用場景與限制

Workers 最擅長的是「請求通過前的輕量邏輯」：依地理或裝置分流、做 A/B 測試、驗證 OAuth token、處理 CORS 標頭、阻擋機器人流量，或將舊路徑改寫到新的 API。限制則在於缺乏傳統檔案系統與部分原生網路能力，且單次請求的 CPU 時間有硬性上限，因此不適合長時間批次運算；這類工作通常交給常駐運算或雲端佇列處理。
