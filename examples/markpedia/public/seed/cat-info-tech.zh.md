## 資訊技術

**Information technology**　軟體、網路與網頁的實用知識。

資訊技術的實用知識可以分成三層：軟體工程處理「怎麼把需求變成可靠系統」，電腦網路處理「怎麼讓資料跨機器流動」，網頁開發則是兩者之上的應用層。

## 收錄條目

| 條目 | 一句話簡介 |
| --- | --- |
| [軟體工程](#/p/software-engineering) | 把需求轉成可維護、可上線軟體的系統化做法 |
| [電腦網路](#/p/computer-network) | 讓設備互相交換資料的通信系統 |
| [網頁開發](#/p/web-development) | 在瀏覽器與伺服器上建構網站應用的技術 |
| [Markdown 記法](#/p/markdown) | 以純文字寫結構化文件的輕量標記語言 |
| [Mermaid 圖表](#/p/mermaid) | 用文字描述流程圖、循序圖等圖表的語法 |
| [Cloudflare Workers](#/p/cloudflare-workers) | 在邊緣節點執行 JavaScript 的無伺服器平台 |
