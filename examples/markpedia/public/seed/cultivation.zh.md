## 概述

**耕作**是作物生產中把土地整理成可播種狀態並持續維護的整套作業，包含整地、播種、施肥、灌溉與田間管理；作業方式直接決定產量、成本與土壤的長期健康。

## 作業流程與整地播種

典型耕作流程為整地、播種、田間管理與收穫。整地包含翻耕、碎土與整平，翻耕深度一般為 $15$ 至 $20$ 厘米，可改善通氣但也會加速有機質分解；播種量依作物與行距而定，稻作直播每公頃種子用量約 $30$ 至 $40$ 公斤，小麥播種量約 $120$ 至 $200$ 公斤。

| 作業 | 目的 | 常用技術 |
| --- | --- | --- |
| 整地 | 翻鬆、整平、混土 | 犁耕、耙地、整平機 |
| 播種 | 建立族群密度 | 條播、點播、育苗移植 |
| 施肥 | 補充養分 | 基肥、追肥、水肥合併 |
| 灌溉 | 供應水分 | 漫灌、溝灌、噴灌、滴灌 |
| 病蟲害管理 | 降低危害 | 輪作、生物防治、綜合防治 |

## 灌溉與水分管理

水稻是需水最多的作物之一，傳統漫灌每生產 $1$ 公斤稻米需耗水約 $2,000$ 至 $3,000$ 升，灌溉同時帶來滲漏與蒸發損失。不同供水方式的效率差距明顯：滴灌可達 $90$ % 以上，噴灌約 $70$ %，漫灌常低於 $50$ %；交替乾濕灌溉可在不減產的前提下節省 $15$ % 至 $30$ % 用水。

## 土壤與養分管理

土壤管理決定地力能否長期維持。全球每年消耗氮肥約 $1.1$ 億公噸氮，其中約三分之一最終以飼料形式進入動物消化道；豆科綠肥每公頃可固定 $80$ 至 $200$ 公斤氮，並同時增加土壤有機碳。免耕搭配覆蓋作物可顯著降低風蝕與水蝕，部分試驗顯示表土流失可減少 $30$ % 至 $80$ %。

## 機械化與智慧農業

機械化程度是農業勞動生產力的核心指標，曳引機與聯合收割機使單人管理面積從數公頃提高到數十公頃。全球在用曳引機約 $360$ 萬台、聯合收割機約 $170$ 萬台，在發展中國家分布尤其不均。近十年更結合全球衛星定位系統、土壤感測器與機器視覺發展出精準農業，據田間試驗可節省 $10$ % 至 $20$ % 的投入品用量。
