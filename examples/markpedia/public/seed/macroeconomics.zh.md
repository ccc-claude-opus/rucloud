## 概述

**總體經濟**（macroeconomics）以整個經濟體為對象，研究總產出、就業與物價如何變動。它處理通膨、景氣循環、失業與政策等必須由政府與央行回應的問題。

## 支出法與國民所得恆等式

以支出法計算，國內生產毛額（GDP）等於消費 $ C $、投資 $ I $、政府支出 $ G $ 與淨出口 $ (X - M) $ 的合計，即 $ Y = C + I + G + (X - M) $。這是會計上的恆等式，但把其中關係改寫成函數即可成為可檢驗的命題；例如消費函數 $ C = a + bY $ 中的邊際消費傾向 $ b $ 介於 0 與 1 之間。

## 乘數效果與景氣循環

一筆政府支出會在再支出過程中累積放大，對總產出的乘數效果為 $ k = \frac{1}{1 - b} $。若 $ b = 0.8 $，乘數為 5，100 美元的最終需求可帶動約 500 美元的產出；實務上因進口漏出與較高的儲蓄傾向，乘數通常小於此。景氣循環指總產出在長期趨勢附近的波動，美國 2020 年實質 GDP 下滑約 3.4 %，是戰後最深的年度衰退。

## 物價、就業與政策工具

| 概念 | 量度方式 | 政策對應 |
| --- | --- | --- |
| 物價膨脹 | 消費者物價指數的年增率 | 收緊貨幣政策或緊縮財政支出 |
| 失業率 | 求職未就業人口占勞動力的比重 | 擴大總需求、推動職業訓練 |
| 實質利率 | 名目利率減去通膨率 | 影響投資與儲蓄的誘因 |
| 貨幣供給 | 流通現金與銀行存款的合計 | 央行以公開市場操作調節 |
