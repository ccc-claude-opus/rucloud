## 統計資料

**Statistics and data analysis**　機率、推論與資料分析。

統計的任務是在資料有限與世界複雜之間取得可用的結論。機率提供語言，推論方法處理不確定性，資料分析則涵蓋從取得到溝通呈現的完整流程。

## 收錄條目

| 條目 | 一句話簡介 |
| --- | --- |
| [機率](#/p/probability) | 以 0 到 1 之間的數表示事件發生可能性的量度 |
| [統計推論](#/p/inference) | 由樣本資料推估母體特徵的方法 |
| [資料分析](#/p/data-analysis) | 檢查、整理與解釋資料以取得結論的過程 |
