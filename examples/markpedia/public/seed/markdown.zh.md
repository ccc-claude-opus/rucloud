## 概述

**Markdown 記法**（Markdown syntax）是由 John Gruber 於 2004 年提出的輕量標記語言，用純文字加上簡單符號表達文件結構，設計目標是「易讀易寫、輸出格式尚可」。它廣泛用於原始碼註解、說明文件與部落格內容，並在 2014 年由 CommonMark 規格釐清了長期的語意歧義。

## 設計理念與規格沿革

Markdown 的語法取自電子郵件與純文字論壇的既有格式慣例，例如以星號表示強調、以連字號表示清單。原始版本沒有正式規範，Gruber 後來也承認部分語意不夠明確，社群因此在 2012 年起推動 CommonMark，2014 年發布 0.9 版，之後由 GitHub 以 GFM（GitHub Flavored Markdown）擴充表格、任務清單、脚註與自動連結等功能。CommonMark 現已成為多數工具的相容性基準。

## 核心語法一覽

Markdown 的語法集中在少數幾種符號的組合上，學習門檻低，卻已涵蓋大部分文件排版需求。由於不需要專用編輯器，任何能輸入純文字的地方都能撰寫，格式再交由渲染器統一處理。

| 寫法 | 結果 | 說明 |
| --- | --- | --- |
| `# 標題` | 標題 | 井號 1 至 6 個分別對應一至六級 |
| `**粗體**`、`*斜體*` | 強調 | 可巢狀使用，星號或底線皆可 |
| `` `行內程式碼` `` | 等寬文字 | 反引號數量多於內容即可包含反引號 |
| `> 引用` | 區塊引用 | 可巢狀，形成引言層級 |
| `- 項目`、`1. 項目` | 清單 | CommonMark 支援巢狀清單 |
| `[文字](網址)` | 連結 | 也可使用參考式連結定義 |
| `![替代文字](網址)` | 圖片 | 語法與連結相同，前加驚嘆號 |
| `---` | 水平分隔線 | 三個以上連字號 |
| 直線分隔的欄列 | 表格 | GFM 擴充，非 CommonMark 核心 |

## 限制與適用情境

Markdown 不提供版面配置、頁首頁尾或樣式控制，也沒有標準的註解、腳註與交叉參照語法，複雜排版仍需仰賴 HTML 標籤或文件轉換工具（如 Pandoc）。因此它最適合技術文件、版本控制中的說明檔、issue 與 pull request 討論；正式出版與簡報排版則通常交由專用格式處理。
