## 概述

**機械**（machine）是由若干構件組成、構件之間具有確定的相對運動，並能完成特定功能或傳遞能量的裝置。機械設計的任務是給定輸入端的運動或功率需求，求出能達成目標、且在效率、成本與壽命上都可接受的機構與零件。

## 構成要素與分類

一部完整的機械通常包含原動機（把燃料或電能轉為機械能）、傳動系統（皮帶、齒輪、軸與軸承）與工作機（執行特定作業的機構），三者加上控制與機座構成整機。依能量形式可分為動力機與工作機：前者如內燃機與電動機，後者如起重機、泵浦與數控機床。判斷性能好壞的第一個指標通常是效率，即輸出功與輸入功之比。

## 機構自由度與確定運動

機構設計的第一步是確認自由度，確認每個構件的運動是否唯一確定。平面機構的自由度可用 Grübler 公式計算：$ n = 3(m-1) - 2j - h $，其中 $ m $ 為構件數、$ j $ 為低副（面對面）數、$ h $ 為高副（點對線）數。例如四連桿有 4 個構件、4 個低副，自由度為 $ 3 \times 3 - 2 \times 4 = 1 $，恰好對應曲柄的一個轉動輸入。

## 效率與常用數據

不同能量轉換途徑的效率差異極大，直接影響系統的能源消耗與散熱設計。功率換算上，$ 1 \ \mathrm{kW\cdot h} = 3.6 \ \mathrm{MJ} $，而 $ 1 \ \mathrm{hp} \approx 746 \ \mathrm{W} $。下表列出常見裝置的效率範圍。

| 裝置 | 典型效率 | 備註 |
| --- | --- | --- |
| 汽油內燃機 | 25 % – 35 % | 排氣與冷卻熱損失占比大 |
| 柴油引擎 | 35 % – 45 % | 壓縮比高，效率優於汽油機 |
| 感應式電動機 | 85 % – 95 % | 結構簡單、維修容易 |
| 同步無刷電動機 | 90 % – 97 % | 需位置感測器與變頻驅動 |
| 單級齒輪傳動 | 97 % – 99 % | 依賴潤滑與齒面精度 |
| 液壓傳動 | 80 % – 90 % | 功率密度大，可用於重載 |
