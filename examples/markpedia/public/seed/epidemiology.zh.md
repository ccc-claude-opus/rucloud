## 概述

**流行病學**（epidemiology）是研究疾病與健康狀態在人群中「分布」與「決定因素」的學科，透過測量與研究設計推估風險，並為公共衛生決策提供證據基礎。

## 學科定位與分支

流行病學廣義上也涵蓋促進健康與預防疾病的介入，依研究目的可分為**描述性**（描述疾病在人群中的分布）、**分析性**（檢驗假設，如病例對照與世代研究）與**實證性**（隨機對照試驗）三大類。與臨床醫學著重個別病人的處置不同，流行病學處理的是群體層次的風險與因果推論，因此同樣一項數據在不同研究設計下可能得到不同的解讀。

## 核心測量指標

**發生率**（incidence）衡量新發病例的速率，**盛行率**（prevalence）衡量某時點既存病例的比例，兩者關係約為 $P = I \times D$，其中 $D$ 為平均病程，因此慢性病即使發生率不高，盛行率仍可能很高。風險比（RR）與勝算比（OR）是分析性研究的常用效果量，前者定義為暴露組與非暴露組發生率之比。

| 指標 | 公式 | 用途 |
| --- | --- | --- |
| 發生率 | 新發人數 / 人時 | 病因探討、風險預測 |
| 盛行率 | 病例數 / 族群人數 | 醫療資源規劃 |
| 相對風險 | $RR = I_e / I_u$ | 暴露的致病強度 |
| 勝算比 | $OR = ad/bc$ | 病例對照研究 |
| 致死率 | 死亡數 / 病例數 | 疾病嚴重度與照護品質 |

## 研究設計與詮釋

病例對照研究由結果回溯暴露，適合罕見病與暴露期長的情況，但容易產生回憶偏差；世代（前瞻性）研究由暴露追蹤結果，較能直接計算發生率與風險比。兩種設計都需處理**混淆因子**，例如吸菸同時與肺癌及心血管疾病相關，未經調整會高估吸菸對心血管的效應。多數觀察性研究的結果屬於**關聯**而非**因果**，解讀時應考慮劑量反應與時序。
