# 入口網站 (Portal)

Yahoo 早期風格的分類網站入口。**純靜態**：不需要 server，直接用瀏覽器開啟 `index.html` 就能用。

## 使用

```bash
# 方式一：直接點兩下 index.html（file://）
open index.html

# 方式二：本機 server
python3 -m http.server 8000   # 開 http://localhost:8000
```

## 三層瀏覽流程

| 畫面 | 內容 | 網址 |
| --- | --- | --- |
| 第一層 | 11 個大類卡片（含子分類標籤、連結數） | `/` |
| 第二層 | 子分類卡片（所屬分類 + 子分類 + 連結數 + 站名預覽） | `#cat=tech` |
| 第三層 | 該子分類的連結，**點站名直接開啟該網站** | `#cat=tech&grp=AI工具` |

頂端麵包屑（首頁 / 大類 / 子分類）隨時回上一層；hash 路由讓重新整理不會跳回首頁，也可直接分享網址。

## 搜尋（兩種模式）

搜尋列旁有「站內 / Google」切換：

| 模式 | 行為 |
| --- | --- |
| 站內 | 即時過濾，結果分三區：**分類**（點了進該分類）、**子分類**（點了進該子分類）、**網站**（點了直接開啟該站）。輸入網址則直接前往；若站內無任何命中，Enter 改送 Google。 |
| Google | 輸入關鍵字後按 Enter 或點「前往 Google 搜尋」，交給 Google 搜整個網路。 |

搜尋結果也可用網址分享：`index.html#q=claude`。

## 檔案

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 頁面骨架：搜尋列 + 模式切換 + 麵包屑 + 內容區 |
| `styles.css` | 緊湊排版（格子同寬同高）、深色模式、RWD |
| `app.js` | 網站資料（`PORTAL`）、hash 路由、兩種搜尋模式 |

## 維護連結

所有連結都在 `app.js` 頂部的 `PORTAL` 陣列：

```js
{
  id: "tech", name: "科技", icon: "💻",
  groups: [
    { name: "AI工具", sites: [
      { name: "ChatGPT", url: "https://chat.openai.com" }
    ]}
  ]
}
```

新增子分類只要在 `groups` 加一個物件，前端自動產生卡片與連結。

## 其他

- 11 大類 × 每類至少 4 個子分類（名稱統一 4 字）、341 個連結
- 所有格子（分類卡／子分類卡／連結卡）固定同寬同高
- 深色／淺色模式，選擇記於 `localStorage`
- RWD，行動裝置卡片自動縮小
